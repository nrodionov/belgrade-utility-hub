🚀 Groq API Deployment Guide

Replace Google Translate with Groq for better translation quality on hm.ss.ru & bg.ss.ru

✅ Changes Committed & Pushed

All code changes have been committed to deploy/dev-setup branch and pushed to GitHub.

Why Groq?

❌ Before (Google Translate)

  • Translates toponyms: "Stari grad" → "Old Town"
  • Translates street names
  • Poor context understanding
  • Sometimes returns error pages

✅ After (Groq + LLM)

  • Preserves ALL toponyms unchanged
  • Keeps street names intact
  • Better context understanding
  • Free: 14,400 requests/day

Step-by-Step Deployment

  1. Get Groq API Key

    Visit console.groq.com and sign up (free, no credit card required).

    1. Go to Settings → API Keys
    2. Click "Create API Key"
    3. Copy the key (starts with gsk_...)
    Note: Save the API key securely — you'll need it for deployment.

  2. Deploy to Dev (hm.ss.ru)

    SSH to the server and pull the latest changes:

    # Connect to server
ssh hm.ss.ru

# Navigate to project
cd /root/selfcheck/belgrade-utility-hub

# Pull latest changes
git pull origin deploy/dev-setup

  3. Set API Key

    Add the Groq API key to the environment:

    # Option 1: Create/edit .env file
echo "GROQ_API_KEY=gsk_your_api_key_here" >> .env

# Option 2: Export directly (temporary)
export GROQ_API_KEY="gsk_your_api_key_here"
    Important: Replace gsk_your_api_key_here with your actual API key from step 1.

  4. Rebuild & Restart Scraper

    Rebuild the scraper container with new dependencies:

    # For dev environment
docker-compose -f docker-compose.yml -f docker-compose.dev.yml build scraper
docker-compose -f docker-compose.yml -f docker-compose.dev.yml up -d scraper

  5. Monitor Logs

    Watch the scraper logs to verify translations are working:

    # Watch logs in real-time
docker logs -f belgrade_scraper_hm

# Look for these messages:
# ✅ "Translation to ru successful via Groq"
# ✅ "Translation to en successful via Groq"
# ❌ "Groq API key not set" (if key missing)

  6. Test Translations

    Compare translations in different languages:

    • hm.ss.ru/?lang=srp — Serbian original
    • hm.ss.ru/?lang=ru — Russian translation
    • hm.ss.ru/?lang=en — English translation
    Check: Municipality names should stay in Serbian (Stari grad, Voždovac, etc.)

Deploy to Production (bg.ss.ru)

After testing on dev and confirming translations work correctly:

# 1. Merge to main branch (locally)
git checkout main
git merge deploy/dev-setup
git push origin main

# 2. On the server
ssh hm.ss.ru
cd /root/selfcheck/belgrade-utility-hub

# 3. Pull and set API key
git pull origin main
export GROQ_API_KEY="gsk_your_api_key_here"  # or add to .env

# 4. Rebuild and restart prod scraper
docker-compose build scraper
docker-compose up -d scraper

# 5. Monitor logs
docker logs -f belgrade_scraper

Technical Details

Translation Model

Using llama-3.1-70b-versatile — fast and high quality for translation tasks.

System Prompt

The model receives explicit instructions to preserve toponyms:

You are a professional translator from Serbian to {target_lang}.

CRITICAL RULES:
1. Keep ALL place names, street names, municipality names EXACTLY as Serbian
2. DO NOT translate: Barajevo, Čukarica, Grocka, Lazarevac, Mladenovac,
   Novi Beograd, Obrenovac, Palilula, Rakovica, Savski venac, Sopot,
   Stari grad, Surčin, Voždovac, Vračar, Zemun, Zvezdara
3. DO NOT translate street names (ulica, bulevar, trg, etc.)
4. Only translate the description of events, problems, and actions

Troubleshooting

Problem: "Groq API key not set"

Solution: Verify GROQ_API_KEY is set in environment or .env file

# Check if key is set
echo $GROQ_API_KEY

# Or check in container
docker exec belgrade_scraper_hm env | grep GROQ

Problem: Translations return original text

Possible causes:

  • API key is invalid or expired
  • Network connectivity issues from container
  • Rate limit exceeded (unlikely with free tier)

Solution: Check logs for specific error messages

Problem: Container fails to start

Solution: Check if groq package installed correctly

# Rebuild from scratch
docker-compose build --no-cache scraper
docker-compose up -d scraper
